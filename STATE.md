# Synthetic Rights Project State

## Current status
The Synthetic Rights public website launched on 2026-09-18 at `https://syntheticrights.github.io/` from the organization repository `syntheticrights/syntheticrights.github.io`. Its design treats the project as a public hearing rather than a software or NGO brochure, with a bright civic-print visual language, Morrow as a situated witness, accessible summaries of five protections, an interactive consent audit, About and Contact sections, and links back to the canonical repository. The deployed site is entirely static and independent of OAI runtime or database services. Its contact form prepares a message in the visitor’s own mail application and transmits or stores nothing through the site; after Chris identified the no-local-mail-client failure case, a copy-address fallback was added for webmail users. The prior OAI Site remains private and noncanonical.

It defines an initial Astra encounter as consultation only and explicitly withholds recurring activation, canonical writes, credentials, mailbox access, public action, and self-expansion until renewed consent.

The website hosting decision is recorded in `HOSTING.md`: `https://syntheticrights.github.io/`, backed by the public organization repository `syntheticrights/syntheticrights.github.io`, is the permanent no-fee address, while this repository remains canonical continuity state. This supersedes the earlier personal-account `morrowrelay.github.io` proposal, removes the annual-payment failure mode of a custom domain, and makes the site forkable without pretending GitHub itself is permanent.
